Evaluation split: The official ISIC-2020 test labels are not publicly available. Following the assignment’s guidance, we report results on a held-out portion of the training data. We perform an 80/20 patient-wise split using GroupShuffleSplit (seed=42) to prevent leakage across splits. All images are already 384×384; we therefore keep resolution fixed and apply identical normalization at train/test time. This protocol supports fair evaluation and reproducibility.
